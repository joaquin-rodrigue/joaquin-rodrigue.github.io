About Me

I'm Joaquin Rodriguez, a software and game developer in Boise State's Games, Interactive Media and Mobile Technology program. I'm here to show off various projects I've worked on throughout the past few years. Enjoy!

Permafrost

An open-world survival horror game made in Unity, combining procedurally generated terrain with resource management and state machine based enemies.

This is my largest project to date, and involved every aspect of indie game development. Programming, systems, 3D art and animation, sound design, UX testing, and more.

I am still developing this game, but plan to publish and release it within the next year.

Here's the project's github repo: https://github.com/joaquin-rodrigue/permafrost

A Simple CMS

This website makes several features of a Content Management System in a simple manner using Node.js, Express, and MySQL.

Making this involved a little of everything, including (but not limited to) dynamic SQL, server-side logic, handling cookies, dynamicly building webpages and CSS, database structuring and management, general JavaScript development, and more.

Here's the project's GitHub repo: https://github.com/joaquin-rodrigue/simple-cms

A Platform Fighter Demo

This Unity game is a demo concept of a 3-dimensional Platform Fighter game, akin to Super Smash Bros.

The game utilizes local multiplayer controls and other general Unity programming.

The project is still a demo, but the idea was unique and I am considering fleshing out the ideas further going forward.

Here's the project's GitHub repo: https://github.com/joaquin-rodrigue/platform-fighter-3d

Buried

This is an old project that was one of my first individual projects in Unity. The game is a 2D platformer using pixel art, level design and programmming made mostly from scratch.

I came back to this project a few times to add some better practice features, and originally used it as a demo for an AR integration using Ultraleap hand tracking sensors.

When I say old, I mean 3 years ago, but the project was a great introduction to both many Unity features and the AR technology I got to use at the time.

Here's the project's Github repo: https://github.com/joaquin-rodrigue/Buried
